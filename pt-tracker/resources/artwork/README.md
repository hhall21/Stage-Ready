# Stage-Ready artwork

These two SVG illustrations were created for Stage-Ready. They contain no
photographs, traced celebrity images or external assets. The website uses them
as decorative visuals with the same dark fades as its interface.

The homepage also draws original posing and squat scenes in
`resources/js/components/HeroAthletes.vue`. Their joint positions and SVG paths
follow the page's scroll progress. A supplied posing GIF was used as a movement
reference; the website renders its own vector figures.

Do not add third-party photographs without a recorded redistribution licence
and any required permission. Private client pose photos belong in protected
upload storage, never in these source assets.
